# Course work

Step-by-step notebooks from the IBM Data Analyst Professional Certificate. They document the techniques behind the final analysis in [`analysis/`](../analysis).

| Folder | Skills |
|---|---|
| `01_data_collection` | REST APIs, web scraping, exporting to Excel |
| `02_data_wrangling` | Duplicates, missing values, normalization (min-max, z-score) |
| `03_exploratory_analysis` | Distributions, outliers (IQR, z-score), correlation |
| `04_data_visualization` | Histograms, box, scatter, bubble, pie, stacked, line and bar charts, SQL queries on SQLite |
