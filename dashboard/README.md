# Dashboard

Interactive dashboard built in IBM Cognos Analytics with three tabs:

1. **Current technology usage:** top languages, databases, platforms and web frameworks used today
2. **Future trends:** what developers want to work with next year
3. **Demographics:** respondents by country, age and education

`dashboard_data_prep.ipynb` turns the raw survey into the summary tables used by each tab.
